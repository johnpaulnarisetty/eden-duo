## 📖 What Is Eden Duo?

Eden Duo is a powerful Nintendo Switch emulator designed specifically for Android devices that have **two screens**, like the AYN Thor. ## 🛠️ Troubleshooting Common Issues

### Game Won't Load
- **Check your ROM file** – Ensure it's a valid Switch game file
- **Update Eden Duo** – Check the releases page for the latest version
- **Restart the app** – Close and reopen Eden Duo

### Slow Performance
- **Lower graphics settings** – Reduce resolution and disable effects
- **Close background apps** – Free up memory for better performance
- **Enable performance mode** – Some devices have a gaming mode in system settings

### Companion Screen Not Working
- **Verify dual-screen support** – Ensure your device has a second display
- **Check screen settings** – Make sure the companion screen is enabled in settings
- **Restart the game** – Some games need a fresh start to sync screens
